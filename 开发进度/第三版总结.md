# 小羊的网络小屋 · 第三版开发总结

> 截至 2026-11-07（北京时间）。本文件汇总此前记录与本轮测试结果；云端状态以实际控制台为准。

## 项目目标与现状

小屋是面向手机浏览器的双人互动网站。GitHub Pages 托管静态页面，Supabase Auth 与 PostgreSQL 提供登录、账号资料和注册限制。正式网站为 [小羊的网络小屋](https://inui-takumi.github.io/little-sheep-house/)。

目前管理员登录与故事主页已开发并发布；第二位用户的注册和邮箱找回仍处于关闭状态。管理员占用第一个名额，第二个名额计划由真实用户通过一次性邀请码和邮箱确认获得。

## 已完成的开发

- 保留七幕互动故事、照片、音乐、卡片、返回、重播与两个结尾分支；主页在会话和资料校验通过后加载故事。
- 建立登录、注册、找回密码和重设密码页面，加入会话保持、账号菜单与退出登录；登录页更新为卡通绵羊，标题使用“全世界最聪明的小羊的网络小屋”。
- 在正式 Supabase 项目中建立两账号资料表、行级安全策略、注册前置 Hook、资料触发器与一次性邀请码哈希结构。正式管理员已初始化，昵称为“全世界最聪明的小羊”。
- 管理员密码由用户报告已重置；重置后的正式站点完整登录回归尚未记录。管理员目前使用内部认证邮箱，不接收邮箱找回邮件；将其改为真实邮箱只是后续讨论，尚未实施。
- 2026-10-30 的记录显示真实 API、本地管理员登录、刷新和退出、原故事交互，以及 320、390、430 CSS 像素宽度检查通过。2026-11-01 登录页改版后，本地静态检查和页面查看通过。
- 功能版本 `4840593` 及登录页更新 `0d2e343` 已推送至 GitHub `main`；2026-11-07 检查时正式页面返回 HTTP 200，显示新标题。

## 邮件服务与独立测试

- 已注册 Brevo、验证手机号、创建 SMTP 密钥，并在正式项目中启用 Brevo 自定义 SMTP。密钥由用户自行填写，不记录在文档或仓库。
- 用户报告 Brevo 直接发信测试成功。独立 Supabase 测试项目 `little-sheep-house-test`（ref：`ldozxltmzdbvfuupqsum`）已配置 Brevo SMTP；确认邮件已收到，测试账号在 Supabase 显示已确认。
- 测试邮件曾进入垃圾邮件。用户没有自有域名，Brevo 对免费邮箱发件人的处理与实际送达情况仍需关注。
- 测试项目原先将确认链接回跳到未运行的 `localhost:3000`；后续设置了独立本地测试回跳页面。用户报告找回密码、更新测试密码以及使用新密码登录成功。
- 上述测试使用独立项目的基础认证流程；测试项目尚未安装小屋的数据库迁移和注册 Hook。它证明测试项目的邮件及认证流程可用，不能替代正式项目及邀请码规则的完整验证。
